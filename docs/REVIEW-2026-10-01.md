# Code review, 2026-10-01

Full-codebase review after phase 6, at commit adeb184. Four reviewers (engine, app, model/UI/build,
and a quick diff pass), each finding verified against the code and, where marked, reproduced with
a throwaway program. Status column is updated by the fix pass.

Severity: **H** high (wrong audio or a release blocker), **M** medium (wrong result in a realistic
case), **L** low (edge case, test gap, cleanup).

## Verified correct by the reviewers

Audio callback is real-time safe (no allocation, lock, log or I/O on the traced call tree; bounded
loops; lock-free atomics). Same-rate latency math is bit-exact and pinned by tests. Resampler
positions, kernel width and capture length are correct and pinned at -80 dB. Sync outlier/median,
confidence tiers, polarity and stall timeout match the design. Float-to-PCM conversion is exact.
Sample counts are 64-bit where needed. FIFO overflow and gaps are counted and tested. Batch state
machine exits from waiting always stop the timer; device loss pauses in every phase; reconnect
never switches under a running batch or sync; Start and Sync guard each other and the dialog.
All `callAsync` paths are guarded; teardown order is correct. Sync store key at lookup matches the
key at store time. Settings read/write types and clamps match; legacy migration never overwrites.
FolderScanner recursion terminates and symlinks are skipped; `scanAsync` is thread-safe and safe
after owner destruction. FileTreeView row indices are never stale. WaveformPanel guards zero
length and width. No stock JUCE styling leaks in disabled states, popup menus or tooltips. JUCE
is pinned by SHA256; the Command Line Tools workaround cannot misfire on a healthy machine.
